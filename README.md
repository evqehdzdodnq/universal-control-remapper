## Overview

Universal Control Remapper (UCR) is a Windows application built on AutoHotkey that captures input from any device — keyboards, mice, gamepads, HOTAS, steering wheels — and routes it through a plugin architecture to virtual vJoy outputs visible to games. It supports layered profiles that switch automatically per active application, complex cross-device routing, and macro sequences with timing control, making it invaluable for accessibility use cases and complex gaming setups.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Universal Control Remapper** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Any Device Input** | Reads keyboards, mice, gamepads, HOTAS, wheels, and joysticks |
| **vJoy Virtual Output** | Creates virtual controller devices recognized by any game or application |
| **Profile Layers** | Layered profiles auto-switch based on the active foreground application |
| **Macro Engine** | Multi-step button sequences with configurable timing per profile layer |
